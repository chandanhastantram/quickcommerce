# QuickCommerce

A modern e-commerce web application built with React and Vite.

## Features

- 🛍️ Product browsing with search and filters
- 🛒 Shopping cart with quantity management
- 💳 Complete checkout flow
- 📦 Order tracking system
- 🎨 Clean white & red design
- ⚡ Fast and responsive

## Live Demo

Visit: [QuickCommerce on Vercel](https://quickcommerce.vercel.app)

## Tech Stack

- React 18
- Vite 7
- Vanilla CSS
- JavaScript (ES6+)

## Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
